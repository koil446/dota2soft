# Справочник предметов и рецептов Dota 2

Небольшое приложение на Python и PyQt6: каталог предметов Dota 2 с рецептами сборки.

Что умеет:
- добавлять и удалять предметы (компоненты, базовые, сборные, нейтральные)
- искать по названию или по части рецепта
- показывать только сборные предметы
- сортировать по цене и считать общую стоимость
- при закрытии сохранять отчёт о работе в report.txt

Запуск:

    pip install PyQt6
    python main.py
